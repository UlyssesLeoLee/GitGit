# CI 工作流片段 (待 Ulysses 接入)

`gitgit` 主仓已有一个 CI workflow(此处不赘述);这个文件是 `gm-desktop` 子目录的**额外 job 模板**,可直接抄进 `.github/workflows/release.yml` 之类。

## 必要 secret / variable

- `TAURI_SIGNING_PRIVATE_KEY` — Tauri updater signing key (V1 用,V0.1 跳过)
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — 同上
- `APPLE_CERTIFICATE` / `APPLE_CERTIFICATE_PASSWORD` / `APPLE_SIGNING_IDENTITY` — macOS only
- `WINDOWS_CERTIFICATE` (base64-encoded .pfx) + `WINDOWS_CERTIFICATE_PASSWORD` — Windows only

## 3-OS matrix(占位)

```yaml
name: gm-desktop-ci

on:
  push:
    paths:
      - 'apps/gm-desktop/**'
      - 'src/**'
      - 'Cargo.toml'
      - 'Cargo.lock'
  workflow_dispatch:

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with: { version: 10 }
      - uses: actions/setup-node@v4
        with: { node-version: 22, cache: pnpm }
      - run: pnpm --filter gm-desktop install --frozen-lockfile
      - run: pnpm --filter gm-desktop lint
      - run: pnpm --filter gm-desktop check
      - run: pnpm --filter gm-desktop test -- --run
        # unit tests only

  test-rust:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo test --manifest-path apps/gm-desktop/src-tauri/Cargo.toml

  build-macos:
    runs-on: macos-latest
    needs: [lint, test-rust]
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with: { version: 10 }
      - uses: actions/setup-node@v4
        with: { node-version: 22, cache: pnpm }
      - uses: dtolnay/rust-toolchain@stable
        with: { targets: aarch64-apple-darwin,x86_64-apple-darwin }
      - run: pnpm --filter gm-desktop install --frozen-lockfile
      - name: Build aarch64
        env:
          APPLE_SIGNING_IDENTITY: ${{ secrets.APPLE_SIGNING_IDENTITY }}
          APPLE_CERTIFICATE: ${{ secrets.APPLE_CERTIFICATE }}
          APPLE_CERTIFICATE_PASSWORD: ${{ secrets.APPLE_CERTIFICATE_PASSWORD }}
        run: pnpm --filter gm-desktop tauri build --target aarch64-apple-darwin
      - name: Build x86_64
        run: pnpm --filter gm-desktop tauri build --target x86_64-apple-darwin
      - uses: actions/upload-artifact@v4
        with:
          name: gm-desktop-macos
          path: |
            apps/gm-desktop/src-tauri/target/aarch64-apple-darwin/release/bundle/dmg/*.dmg
            apps/gm-desktop/src-tauri/target/x86_64-apple-darwin/release/bundle/dmg/*.dmg

  build-windows:
    runs-on: windows-latest
    needs: [lint, test-rust]
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with: { version: 10 }
      - uses: actions/setup-node@v4
        with: { node-version: 22, cache: pnpm }
      - uses: dtolnay/rust-toolchain@stable
      - run: pnpm --filter gm-desktop install --frozen-lockfile
      - name: Build MSI
        run: pnpm --filter gm-desktop tauri build
      - uses: actions/upload-artifact@v4
        with:
          name: gm-desktop-windows
          path: apps/gm-desktop/src-tauri/target/release/bundle/msi/*.msi

  build-linux:
    runs-on: ubuntu-latest
    needs: [lint, test-rust]
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with: { version: 10 }
      - uses: actions/setup-node@v4
        with: { node-version: 22, cache: pnpm }
      - uses: dtolnay/rust-toolchain@stable
        with: { targets: x86_64-unknown-linux-gnu }
      - run: sudo apt-get update && sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev
      - run: pnpm --filter gm-desktop install --frozen-lockfile
      - name: Build AppImage + deb
        run: pnpm --filter gm-desktop tauri build
      - uses: actions/upload-artifact@v4
        with:
          name: gm-desktop-linux
          path: |
            apps/gm-desktop/src-tauri/target/release/bundle/appimage/*.AppImage
            apps/gm-desktop/src-tauri/target/release/bundle/deb/*.deb

  bundle-size-check:
    runs-on: ubuntu-latest
    needs: [build-macos, build-windows, build-linux]
    steps:
      - uses: actions/download-artifact@v4
      - name: Assert each artifact < 30 MB
        run: |
          for f in $(find . -type f \( -name '*.dmg' -o -name '*.msi' -o -name '*.AppImage' -o -name '*.deb' \)); do
            size=$(stat -c %s "$f")
            if [ "$size" -gt 31457280 ]; then
              echo "::error::artifact $f is $size bytes (> 30MB)"
              exit 1
            fi
          done
```

## 占位说明 / Placeholder notes

- **不直接 push 到 `.github/workflows/`**:该动作由 Ulysses 拍板,worker 留 snippet 即可(per 8/27/9/8 强化 "Ulysses 拍板"). 真正接 CI 时请 `cp` 此片段到 `D:\GitGit\.github\workflows\gm-desktop-ci.yml`,并按需调整 trigger / environment 段。
- **`lint` 与 `test-rust` 是 fastlane 必经**;`build-*` 是 release-only(trigger 改成 `on: workflow_call` 或手动 `workflow_dispatch`)。
- **`bundle-size-check` 是商业产品硬底线**(per brief),< 30MB 阈值。

## 触发场景

- 接到 `release` tag → 自动 build 三平台,产物上传到 GitHub Releases(配 `tauri-action` 插件)
- PR 提交流 → 只跑 lint + test-rust(便宜),不跑 build-*
- 手动 `workflow_dispatch` → debug 验证某个平台

> **警告**:V0.1 本会话尚未真正 pack 过一次 `tauri build`(单平台首次 build ~10 分钟,3 平台 * 2 target ≈ 1 小时),CI 接入后第一跑务必看明白 logs 才能开签名。
