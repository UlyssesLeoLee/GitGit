# ADR-0001: 采用 Rust 作为主语言

> **Status**: Accepted
> **Date**: 2026-08-19
> **Deciders**: SA + TL + EM
> **Consulted**: SEC + PO
> **Informed**: 全体

## Context and Problem Statement

项目需要一门主语言承载：HTTP API / Git 服务 / Agent runtime / AI gateway。考虑候选：Rust / Go / TypeScript(Node.js) / Python。

## Decision Drivers

- 内存安全（处理不可信 Agent 输入）
- 二进制体积小 + 启动快（Local-First 自托管）
- 并发性能（Tokio async runtime）
- 与 PostgreSQL / Git 生态兼容

## Considered Options

1. **Rust + Tokio + Axum**
2. **Go + net/http**
3. **TypeScript + Node.js / Bun**

## Decision Outcome

**Chosen option**: "Option A (Rust)", because Option A (Rust)。依据：MVP 阶段处理不可信 Agent 输入，需要内存安全；Local-First 单二进制部署要求小体积 + 启动快；Tokio async 性能满足 NFR-REQ-002。

### Consequences

**Good:**
- [+] 单二进制 < 100MB
- [+] 无 GC 暂停，延迟稳定
- [+] 强类型 + 编译期错误捕获

**Bad:**
- [-] 开发节奏比 Go 慢 1.5x
- [-] 新人 onboarding 周期长

### Confirmation

tech-selection.md §2 / 实施前 QA §6 ADR-001 已记录；MVP 完成时 binary size 验证

## Pros and Cons of the Options

### Rust + Tokio + Axum

[+] 内存安全无 GC；启动快；单二进制发布；强类型；async 性能强
[-] 学习曲线陡；编译慢；async + lifetime 心智负担

### Go + net/http

[+] 上手快；GC 简单；gofmt 自动；并发模型清晰
[-] GC 暂停不适合硬实时；错误处理较繁琐；二进制偏大

### TypeScript + Node.js / Bun

[+] (see chosen)
[-] (see chosen)
